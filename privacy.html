개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-11-24

한국어

  1. 서비스 소개: Brom Uploader는 자사 채널(손해안봄, 썰터는카피바라)에 자사가 제작한 영상을 올리기 위한 내부 도구입니다.
  2. 수집 정보: 구글 계정의 유튜브 채널 정보와 영상 업로드 권한 토큰(OAuth)만 사용합니다. 그 밖의 개인정보는 수집하지 않습니다.
  3. 보관: 토큰은 사용자의 로컬 컴퓨터에만 저장되며 외부 서버로 전송하지 않습니다.
  4. 제3자 제공: 수집한 정보를 제3자에게 제공, 판매, 공유하지 않습니다.
  5. 권한 해제: myaccount.google.com/permissions에서 언제든 접근 권한을 해제할 수 있습니다.
  6. Google API 정책: Google API 서비스에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.
  7. 문의: GitHub Issues

English

  1. About: Brom Uploader is an internal tool for uploading videos we produce to our own YouTube channels.
  2. Data collected: Only the YouTube channel information of the Google account and the OAuth token granting video upload permission. No other personal data is collected.
  3. Storage: The token is stored locally on the user's own computer and is not sent to any external server.
  4. Third parties: We do not share, sell or disclose this data to any third party.
  5. Revoking access: You can revoke access at any time at myaccount.google.com/permissions.
  6. Google API Services User Data Policy: The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  7. Contact: GitHub Issues
